Magic Tiles Strain Now Puts Phantom Tiles in the Starting Pool (1.5.6)

Patch 1.5.6 changed the Magic Tiles Strain so phantom tiles are in the pool of tiles available at the start of a run. A version-change read on what that means for staging, without inventing pool rates.

Advertisement
MID GAME

The entire 1.5.6 line about Magic Tiles is one sentence: phantom tiles are now in the pool of tiles available at the start. If you were treating your opening board as a fixed set of possibilities, that sentence changes what you check in staging.

It is a pool change, not a new tile. The tile and its behaviour already existed. What 1.5.6 changed is that the Strain can now offer it among the tiles available when a run begins.

THE ONE-SCREEN ANSWER

With Magic Tiles active, your starting board can include phantom tiles. Read the board in staging instead of assuming the old pool, and do not spend a tile token on a square you already have a phantom answer for. No drop rates or pool sizes were published, so none are claimed here.

The tile control guide covers tile interactions across a run; this page stays on the one 1.5.6 pool change and the opening decisions it affects.

Read the Note Literally

The 1.5.6 post says: Magic TIles Strain add phantom tiles in the pool of tiles available at start, credited to a Discord report. That is a bug-fix-shaped sentence about a pool that was missing an entry. It is not a balance change to the tile, and the developer gives no weighting, no count and no probability.

So the honest conclusion is narrow. If you play with Magic Tiles, the set of tiles that can appear on your opening board is now one entry wider. Everything downstream of that is a decision you make in staging, not a number anyone has published.

The difficulty and progression guide explains where Strains sit relative to the six difficulty tiers. Strains and difficulty both add modifiers to a run, but a pool change like this one acts at run creation while difficulty tiers act on the rules of the whole run.

  • A pool is not a guarantee. A tile being in the pool does not mean it appears in your opening. Do not build a plan that requires it.
  • Staging is where it matters. You can see the enemy formation and adjust your own positions before the game starts; that is the moment to read which tiles are actually present.
  • The custom boards reference and the how to play page are the right background if the opening board setup is still unfamiliar.

The Decision It Actually Changes

Every shop offers three random tokens, and a tile token gives you a random tile modifier on a square you choose. The interesting part is that the modifier is random but the placement is not. If phantom tiles can already be on the board at run start, your first tile token decision has one more board state to account for.

Quick reference, no table needed

On Phantom tile already present in a useful square: You already have that answer. On Phantom tile present in a bad square: Placement is the part you control. On No phantom tile present: A wider pool is not a guarantee. On Boss preview names a board problem: The preview outranks a tile gamble.

Do not turn a pool fix into a strategy

There is no published rate for how often phantom tiles appear at start, and no claim here that they are good or bad in the opening. The token decision guide gives the run-state test; the pool change only adds one more thing to look at before you apply it.

That restraint is deliberate. This site has a standing rule against inventing run data, and a one-line pool fix is exactly the kind of note that attracts confident-sounding percentages with nothing behind them.

The Rest of 1.5.6, For Context

The same post fixed three other things: no breakage when spamming Esc after Pause to Main Menu, enemies clearing their old tile reliably, and no error when a cursed tile’s piece disappears before the curse triggers. Two of those are board-state fixes. If your read of a fight felt off in October, a leftover visual or a stale tile may have been why.

Version check: 1.5.6 is dated 30 October 2026. The 1.5.4b fix checklist covers the previous batch, and 1.5.7 followed on 2 November with two Gambit trigger changes. None of these posts change the five-Gambit cap or the run structure.

Pro tip:
One habit for every pool change
Spend two seconds reading every square in staging before you spend anything in the shop. A wider pool only rewards players who actually look at what they got.

For the full tile vocabulary, the tile control guide remains the reference; this page is only the delta that 1.5.6 introduced.
