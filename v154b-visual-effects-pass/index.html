You Can Finally See When a Gambit Fires: The 1.5.4b Visual Effects Pass

Patch 1.5.4b added missing visual effects to eight named Gambits. The full list, why a new effect is not a buff, and how 1.5.7's Dainsleif trigger fix differs from an art pass.

Advertisement
MID GAME

Eight Gambits got their missing visual effects on 30 September 2026. Nothing about their numbers changed, but a Gambit you can see firing is a Gambit you can actually debug in the middle of a run.

The official ART line names all eight: Dainsleif’s, King XI’s, Resurrection Stone’s, Anna’s Family’s, Zen’s, Jockey’s, Princess’s and Warlock’s Gambit.

THE ONE-SCREEN ANSWER

An art pass is not a balance pass. If one of these eight suddenly looks like it is doing more, that is because you can finally see it. Check the effect text with a hover before you rebuild a combo around a visual you had simply been missing.

The Gambits overview covers the five-slot cap and how offers appear; this page is only the 1.5.4b art list and the 1.5.7 trigger fix that followed it.

The Eight, Exactly as Listed

The 1.5.4b post groups these under ART, not DESIGN or FIX: added missing visual effects to several Gambits. Here they are in the order the developer gave them.

  • Dainsleif’s Gambit - also the subject of a separate 1.5.7 trigger fix, which is a real rule change and easy to confuse with the art pass.
  • King XI’s Gambit - visual effect added.
  • Resurrection Stone’s Gambit - visual effect added.
  • Anna’s Family’s Gambit - visual effect added.
  • Zen’s Gambit - visual effect added.
  • Jockey’s Gambit - visual effect added.
  • Princess’s Gambit - visual effect added.
  • Warlock’s Gambit - visual effect added.

Why this matters more than it sounds. You can hold five Gambits at once. When several of them can fire in the same turn, knowing which one actually resolved is the difference between a repeatable combo and a lucky board. Before this pass, four of those eight gave you no visual confirmation at all.

Patch 1.5.3 also fixed the info layer: pressing Pause or Info while hovering a Piece or a Gambit now shows the description in front of the menu, and the Gambit collection tab was optimised. Read together with the art pass, hovering plus a visible effect is now the fastest way to check a trigger without leaving the game.

The 1.5.7 Dainsleif Line Is Different

On 2 November 2026 the developer posted: Dainsleif’s Gambit now triggers when a KING is turned to Gold thanks to another Gambit, credited to a Discord bug report. That is a trigger fix. The same Gambit got a missing visual effect in 1.5.4b. Two patches, two different kinds of change, one name.

  • 1.5.4b (30 Sep): Added missing visual effects / ART - feedback only
  • 1.5.7 (2 Nov): Now triggers when a KING is turned to Gold by another Gambit / FIX - trigger condition
  • 1.5.7 (2 Nov): Golden Idol’s Gambit proc chance 1/3 to 1/2 / DESIGN - rate change

Conflating the two is how a tier list ends up claiming an art pass was a buff. The Gold Tile reference is the right background for the KING-into-Gold interaction; this page is only drawing the boundary between seeing an effect and changing an effect.

Visible is not stronger

If a Gambit suddenly seems to fire more often after 1.5.4b, check whether you are simply noticing it now. The only proc rate change in this release window is Golden Idol’s Gambit in 1.5.7, and that one is covered in the odds breakdown.

A Practical Way to Use the New Feedback

When a combo collapses, the failure is usually one trigger that never happened. With the eight effects visible, you can watch a turn and name the missing link instead of guessing. That is a debugging habit, not a new build.

  • Hover before you commit. 1.5.3 fixed the info panel layering, so the description is readable even with Pause or Info open.
  • Watch one trigger at a time. In a five-Gambit setup, confirm the first effect resolves before assuming the chain is intact.
  • Do not re-rank on sight. The 1.5.0 to 1.5.3 breakdown and the 1.5.4b design changes are where the actual rule changes live.
Pro tip:
Before you rebuild a combo
Ask one question: did the rule change, or can I just see it now? The art pass answers the second. Only the 1.5.4b fix checklist and the 1.5.7 post answer the first.

If you are new to reading Gambit text, the how to play page defines the slot system and the shop loop before you start tracing chains.
